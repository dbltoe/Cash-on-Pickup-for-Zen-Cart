# Cash on Pickup for Zen Cart

Lets a customer order online and pay cash when they pick the order up. It's offered only when they choose Store Pickup shipping, on the standard checkout and on One Page Checkout.

- Encapsulated plugin, Zen Cart 1.5.8 through 3.0.0, PHP 7.4 through 8.5
- Settings under Modules > Payment
- Needs Zen Cart's own Store Pickup shipping module

## Installing

1. Upload `zc_plugins` to your store's main folder.
2. On Zen Cart 1.5.8 through 2.1.x only, also upload the `includes` folder from `for_zen_cart_1.5.8_to_2.1.x`.
3. Install **Cash on Pickup** under Modules > Plugin Manager.
4. Click **Settings**, then install and set it up under Modules > Payment.

Moving from v2.0.0 or earlier? Delete the old files first: [docs/INSTALL.md](docs/INSTALL.md) has the list. Your settings and past orders carry over.
